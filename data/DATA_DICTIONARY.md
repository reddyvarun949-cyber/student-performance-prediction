# Data dictionary — student_performance.csv

Synthetic data for a fictional college, generated by `generate_data.py` (seed 7). 2,000 unique students plus
30 duplicated rows added on purpose. Licence: created for this course; free to use and share.

All columns except `final_score` describe what the college knows **around week 5 of the term**.

| Column | Type | Description | Values / range | Missing | Used as feature? |
|---|---|---|---|---|---|
| `student_id` | text | Row identifier | S00001–S02000 | none | No (just a label) |
| `gender` | category | Gender | Female, Male | none | **No** — kept only for the fairness check |
| `age` | integer | Age in years | 18–24 | none | No (no relationship with the target) |
| `study_hours_per_week` | number | Self-reported self-study hours per week | 0–31.3, plus impossible values −5, 168, 200 | 45 rows | Yes |
| `attendance_pct` | number | Attendance so far this term (%) | 39.2–100, plus impossible values 101.5, 105, 110, 120, 150, 999 | 30 rows | Yes |
| `previous_sem_gpa` | number | GPA of the previous semester (0–10 scale) | 3.0–10.0 | none | Yes |
| `assignments_submitted_pct` | number | Share of assignments submitted so far (%) | 39–100 | none | Yes |
| `internal_test_score` | number | Week-5 internal test, out of 50 | 7–50 | none | Yes |
| `part_time_job` | category | Works part-time | Yes, No | none | Yes |
| `commute_minutes` | number | One-way travel time to college | 5–120 | 25 rows | Yes |
| `family_support` | category | Support at home for studies | Low, Medium, High | 36 rows | Yes |
| `internet_access` | category | Reliable internet at home | Yes, No | 20 rows | Yes |
| `extracurricular` | category | Takes part in clubs or sports | Yes, No | none | Yes |
| `sleep_hours` | number | Average sleep per night | 4–10, plus impossible values −1, 0, 24, 30 | 40 rows | Yes |
| `final_score` | number | Final exam score (0–100), known only at the **end** of term | 3–94 | none | **No — leakage** (see below) |

Missing counts above include the duplicated rows.

## The target: `at_risk`

The notebook creates `at_risk = 1` when `final_score < 40` (the pass mark), else `0`. About **19%** of the unique
students are at risk, so the classes are imbalanced.

**Why `final_score` is dropped after creating the target:** it is only known after the final exam. A model that sees
it would just learn "below 40 → at risk", look perfect in the notebook, and be useless in week 5 when a mentor needs the
prediction. Using information that is not available at prediction time is called *data leakage*.

## Deliberate messiness

- **Missing values** in six columns (forms left blank).
- **Impossible values** (typing mistakes): attendance above 100%, negative or 24+ hours of sleep, 168–200 study hours a
  week. The notebook turns them into missing values.
- **30 duplicated rows** (the same student entered twice). The notebook removes them before splitting.

## How the scores were generated

A hidden "motivation" value links habits together (motivated students attend, study and submit more). The final score is
roughly `−8.7 + 3.2·GPA + 0.55·internal test + 0.22·attendance + 0.35·study hours + 0.08·assignments − 0.06·commute
− 2.5·|sleep − 7.5| + family-support effect − 2 if no internet + 1 if extracurricular`, plus random noise
(standard deviation 7), clipped to 0–100. A part-time job has no direct effect: it lowers study hours, attendance and
sleep instead. **Gender has no effect at all**, which lets students test whether the model treats groups fairly.
